# SauceDemo Autotests

Учебный проект UI-автотестов для демо-магазина [saucedemo.com](https://www.saucedemo.com/).

## Стек

- Java 17
- Maven
- Selenium WebDriver 4
- JUnit 5
- Allure Report

## Что проверяется

**Авторизация**
- успешный вход с верными данными;
- негативные сценарии (параметризованный тест): неверный пароль, заблокированный пользователь, пустой логин, пустой пароль.

**Корзина**
- добавление товара в корзину;
- удаление товара из корзины.

## Особенности проекта

- паттерн **Page Object** с базовым классом `BasePage`;
- **явные ожидания** (`WebDriverWait`) вместо `Thread.sleep`;
- **параметризованные тесты** (`@ParameterizedTest` + `@CsvSource`);
- **Allure-отчёт** с шагами (`@Step`), разделами (`@Epic`, `@Feature`) и важностью тестов (`@Severity`);
- **скриншот при падении** теста автоматически прикрепляется к отчёту;
- тестовые данные вынесены в отдельный класс `TestData`.

## Структура

```
src/test/java
├── pages     — Page Object: страницы сайта и действия на них
├── tests     — тесты и базовый класс BaseTest
└── utils     — тестовые данные и расширение для скриншотов
```

## Запуск

Требования: JDK 17+, Maven, Google Chrome.

```bash
# запустить все тесты
mvn clean test

# открыть Allure-отчёт в браузере
mvn allure:serve
```
